# ⚡ Quick Start Guide

<div align="center">

## 🚀 Get Started in 60 Seconds!

**The fastest way to master Sound Manager**

</div>

---

## 📥 Step 1: Launch (5 seconds)

```
Double-click → sound_manager_gui.py
              (or the .exe file)
```

**Result:** Window appears in bottom-right corner! ✨

---

## 🎵 Step 2: Play Audio (10 seconds)

```
Open Spotify/YouTube/Any app
    ↓
Play some music or video
    ↓
App appears in Sound Manager! 🎉
```

---

## 🎚️ Step 3: Control Volume (15 seconds)

### Drag the Slider

```
┌─────────────────────────────────────────┐
│  🎵 Spotify                         🔊  │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  75% │
   ↑ Click here and drag left/right
```

**Try it:**
- Drag **left** → Quieter 🔉
- Drag **right** → Louder 🔊

---

## 🔇 Step 4: Mute (20 seconds)

### Click the Speaker Icon

```
Before:  🔊 (Green)  → Click
After:   🔇 (Red)    → Muted! 🤫
```

**Click again to unmute!**

---

## 🙈 Step 5: Hide Apps (30 seconds)

### Right-Click to Exclude

```
1. Right-click any app
   ┌─────────────────────────────┐
   │ Exclude from monitoring     │
   └─────────────────────────────┘

2. Click "Exclude from monitoring"

3. App disappears! ✨
```

---

## ⚙️ Step 6: Manage Exclusions (45 seconds)

### Open Settings

```
1. Click ⚙️ button (bottom-right)

2. See excluded apps:
   ┌───────────────────────────────────┐
   │ chrome.exe                        │
   │ spotify.exe                       │
   └───────────────────────────────────┘

3. Select one → Click "Remove Selected"

4. App comes back! 🎉
```

---

## 🪟 Step 7: Customize Window (60 seconds)

### Move & Resize

**Move:**
```
Click anywhere → Drag → Release
Position saved! 💾
```

**Resize:**
```
Hover over edge → Cursor changes ↔️
Drag left/right → Resize!
Width saved! 💾
```
